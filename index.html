Before each update, the dashboard saves itself as one HTML file per day, for example Zyax Board Dashboard 2026-10-22.html. Open any archived file to see that day exactly as the board saw it.
One-time setup (about 3 minutes, no Google Cloud project)
  1. Open script.google.com while signed in as the Google account that should hold the archive, and click New project.
  2. Delete what is in the editor and paste the script below (). It already contains your private archive key.
  3. Click Deploy → New deployment, choose type Web app. Set Execute as: Me and Who has access: Anyone, then Deploy.
  4. Approve the access request. If Google says the app isn’t verified, click Advanced → Go to (project name); it is your own script.
  5. Copy the Web app URL (ends in /exec), paste it above and press Connect and test.

The script can only create and update files in the archive folder, and only when the request carries your key. To change the key, edit it in both places.

Pick the folder once, ideally inside your Google Drive for desktop drive (for example G:\My Drive\Zyax Board Dashboard Archive). Files saved there sync to Drive automatically. Works in Chrome and Edge.
